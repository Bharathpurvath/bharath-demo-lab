# Bharath B — Demo Lab

A responsive project gallery with a working ApplyFlow Job Tracker browser demo.

## What's included

- **ApplyFlow Job Tracker:** add, edit, search, filter, and delete job applications.
- **Local persistence:** demo data is saved in your browser with localStorage.
- **Reset sample data:** restore the starter examples at any time.
- **FileBuddy:** link to the existing live FileBuddy project.
- Responsive layout for desktop and mobile.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site.

Expected site URL: https://bharathpurvath.github.io/bharath-demo-lab/

## Notes

- The ApplyFlow demo uses sample data and is not connected to a production backend.
- Data is stored only in the browser used to open the demo.
- Sample application dates are illustrative.
